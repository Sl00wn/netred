# 🌐 NetPulse // Интерактивный хаб сетевого инженера

[![Vite](https://img.shields.io/badge/Vite-6.x-646CFF?logo=vite&logoColor=white)](https://vitejs.dev/)
[![Version](https://img.shields.io/badge/version-2.7.0-0da9f3.svg)]()
[![License: MIT](https://img.shields.io/badge/License-MIT-a3e635.svg)](LICENSE)
[![Style: Colorpong Data Strings](https://img.shields.io/badge/Aesthetics-Colorpong%20Data%20Strings-e0248a.svg)]()

Современный высокопроизводительный веб-портал, интерактивная рабочая станция и база знаний для сетевых инженеров, системных архитекторов и администраторов. Интерфейс выполнен в премиальной стилистике **Colorpong Data Strings** (темная обсидиановая тема, неоновые векторные струны, стеклянные панели glassmorphism и удобная панель управления в формате современного Cloud/Admin Dashboard).

---

## ⚡ Быстрый старт

### 1. Клонирование и установка зависимостей:
```bash
git clone https://github.com/ВАШ_АККАУНТ/network-engineer-hub.git
cd network-engineer-hub
npm install
```

### 2. Запуск локального сервера разработки (HMR):
```bash
npm run dev
```
Портал откроется по адресу: **`http://localhost:5173`**.

### 3. Сборка для Production:
```bash
npm run build
```
Оптимизированный статический бандл формируется в папке `dist/` и готов к деплою на Vercel, Netlify, Cloudflare Pages или GitHub Pages.

### 4. Предпросмотр Production-сборки:
```bash
npm run preview
```

## 🚀 Основные модули и функционал

### 1. 📖 Словарь понятий & RFC (Cyber Lexicon)
- Более 120 подробных терминов и протоколов (BGP, OSPF, MPLS, VXLAN, EVPN, WireGuard, IPsec, QUIC, SRv6 и др.).
- Практические конфигурационные шаблоны CLI для **Cisco IOS/NX-OS**, **Linux (`iproute2`, `nftables`)**, **Juniper JunOS** и **MikroTik RouterOS**.
- Блоки диагностики и траблшутинга (команды проверки состояния, дампы трафика, типичные ошибки).
- Мгновенный поиск по терминам, описаниям, протоколам и номерам RFC (<kbd>⌘K</kbd> / <kbd>/</kbd>).
- Система закладок (Избранное) с сохранением в `localStorage`.

### 2. 🗺️ Интерактивный стек OSI (7 уровней)
- Наглядная архитектурная модель взаимодействия открытых систем.
- Фильтрация понятий и протоколов по выбранному уровню (от L1 Physical до L7 Application).
- Детальное описание блоков данных (PDU: Bits, Frames, Packets, Segments, Data).

### 3. 🧮 Калькулятор подсетей (CIDR & VLSM)
- Мгновенный расчет сетевых адресов, масок подсетей, инверсных масок (Wildcard) и broadcast.
- Расчет доступных хостов (с поддержкой RFC 3021 `/31` для P2P линков и `/32` для loopback).
- Интерактивная 32-битная бинарная карта IP-адреса с цветовой дифференциацией битов сети и хоста.
- Определение класса сети, типа адреса (Private RFC 1918, Loopback, Carrier-Grade NAT, Link-Local, Public).

### 4. 📡 Пошаговый симулятор протоколов
- Интерактивная анимация движения сетевых пакетов между узлами.
- Визуализация алгоритмов:
  - **TCP 3-Way Handshake** (`SYN` ➔ `SYN-ACK` ➔ `ACK`)
  - **ARP Address Resolution** (Broadcast Request ➔ Unicast Reply)
  - **DNS Resolution** (Recursive/Iterative Query)
  - **DHCP DORA** (`Discover` ➔ `Offer` ➔ `Request` ➔ `Pack`)

### 5. 🔌 Справочник сетевых портов
- Обширная база данных стандартных портов IANA и популярных сервисов TCP/UDP.
- Поиск по номеру порта, транспортному протоколу, названию службы и описанию.

### 6. 🕸️ Конструктор и эмулятор топологии сети (Topology Simulator)
- Интерактивный Drag-and-drop холст для проектирования сетевых схем.
- Поддержка сетевых узлов: Маршрутизаторы, Коммутаторы L2/L3, Серверы, Рабочие станции, Межсетевые экраны (Firewall), Облака (Internet).
- Соединение узлов динамическими линками с расчетом задержек.
- **Инспектор устройств**: настройка IP-адресов, масок, шлюзов по умолчанию.
- **Интерактивный Ping**: пошаговая BFS-симуляция прохождения пакетов с анимацией полета по кабелям и логом событий.
- **✨ Text-to-Topology AI Generator**: автоматическое построение архитектуры сети по текстовому описанию на русском языке либо по готовым шаблонам (Enterprise DMZ, Office VLANs, Data Center Spine-Leaf, Branch WAN).

## 🎨 Дизайн и архитектура интерфейса

- **Эстетика Colorpong Data Strings**:
  - Генеративный Canvas2D-движок с 5 хроматическими жгутами векторных струн (Electric Cyan `#0da9f3`, Cyber Magenta `#e0248a`, Electric Violet `#8b5cf6`, Acid Lime `#a3e635`).
  - Физика гравитационного натяжения струн курсором (String Plucking) и затухающие резонансные импульсы по нажатию <kbd>Space</kbd>.
  - Стабильные 60 FPS с нулевой аллокацией памяти в цикле рендера (Zero-Allocation Loop).
- **Архитектура Cloud/Admin Dashboard**:
  - Верхний закрепленный топбар с поиском, телеметрией и быстрыми кнопками.
  - Левая вертикальная панель навигации (Sidebar): быстрые карточки 2x2, удобный список разделов с горячими клавишами, возможность свернуть меню в компактную панель иконок.
  - Вкладки больше не требуют горизонтальной прокрутки и всегда доступны в один клик.
- **Синтезатор звука Web Audio API**: программно генерируемые футуристичные звуковые отклики для кликов, импульсов и уведомлений.

## ⌨️ Горячие клавиши

| Клавиша | Назначение |
|---|---|
| <kbd>1</kbd> — <kbd>6</kbd> | Мгновенный переход между разделами хаба |
| <kbd>⌘K</kbd> или <kbd>/</kbd> | Фокус на строку глобального поиска |
| <kbd>Space</kbd> | Запуск резонансного импульса по струнам фона |
| <kbd>M</kbd> | Включение / выключение звуковых эффектов |
| <kbd>?</kbd> | Окно справки по горячим клавишам |
| <kbd>Esc</kbd> | Закрытие любого открытого модального окна |

## 📁 Структура проекта

```
network-engineer-hub/
├── index.html              # Главная точка входа приложения
├── package.json            # Зависимости и метаданные проекта
├── vite.config.js          # Конфигурация сборщика Vite
├── .gitignore              # Исключения версионного контроля
├── public/
│   └── favicon.svg         # Векторный фавикон приложения
└── src/
    ├── main.js             # Точка входа скриптов
    ├── styles/

    └── scripts/
        ├── app.js          # Главный контроллер хаба и роутинг
        ├── audio.js        # Web Audio API синтезатор
        ├── cyber-canvas.js # Генеративный Canvas-движок струн данных
        ├── data.js         # База знаний протоколов, портов и симуляций
```
